🐰 Web Transcoder

Local video transcoding in your browser, powered by Mediabunny. Files are processed on this machine and never leave it.

Auto mode: a video stream is re-encoded when its bitrate is more than 1.5× the recommended value for its resolution & frame rate (e.g. ~8 Mbps for 1080p30).
“Video only” is a per-file setting (default: on) — toggle it on each file’s card, or use the global switch above to set it for all files at once.
